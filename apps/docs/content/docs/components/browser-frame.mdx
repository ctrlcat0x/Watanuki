---
title: Browser frame (Safari)
description: Frame screenshots and product previews in browser chrome.
---

Browser frames give screenshots enough product context to feel like a real page instead of a loose image. The URL bar and familiar chrome help readers understand that they are looking at a browser experience, preview, or finished result.

## When to use it

- Product walkthroughs and feature announcements
- Landing-page or dashboard previews
- Showing the expected result after a setup tutorial

## Why it helps

Use the frame when browser context improves comprehension or presentation. For diagrams, photos, or screenshots where chrome adds no meaning, use a regular image or `Media` instead.

## Example

Safari-style browser chrome for screenshots and product previews.

```tsx
import { Safari } from '@watanuki/ui/components/safari'

<Safari url="watanuki.dev" imageSrc="/placeholder-1200x700.svg" />
```
